# Notes 

Android-приложение для создания и управления заметками для лаборатории ШИФТ

## Основные возможности
*   Создание заметок с заголовками, тегами и текстом
*   Вставка изображений из галереи и возможность создания изображения с помощью камеры
*   Поиск по заголовкам, тегам и содержимому

---

## Инструкция по сборке

### 1. Требования к среде
Для успешной сборки вам понадобятся:
*   Android Studio
*   JDK 17 или выше
*   Android SDK 37
*   Устройство или эмулятор с Android 7.0 (API 24)

### 2. Подготовка проекта
1.  Склонируйте репозиторий
2.  Запустите Android Studio и выберите `File -> Open`, укажите путь к корневой папке проекта
3.  Дождитесь завершения синхронизации или нажмите значок (Sync Project with Gradle Files)

### 3. Сборка из интерфейса Android Studio
1.  Выберите модуль `app` в списке конфигураций запуска
2.  В панели нажмите на  `Assemble app Run Configuration` (или `Build -> Make Project`)
3.  Сообщение `BUILD SUCCESSFUL` подтвердит успех сборки

### 4. Сборка через терминал (CLI)
Используйте Gradle Wrapper для управления сборкой:

*   **Сборка отладочной версии (Debug APK):**
    ```bash
    ./gradlew assembleDebug
    ```
    *Результат (APK): `app/build/outputs/apk/debug/app-debug.apk`*

### 5. Запуск приложения
1.  Подключите Android-устройство или запустите эмулятор.
2.  Нажмите кнопку Run .

## Используемые библиотеки

### 1. Jetpack Compose
*   Это современный декларативный UI-фреймворк от Google. Он позволяет описывать интерфейс кодом на Kotlin, что значительно ускоряет разработку, уменьшает объем кода (по сравнению с XML) и решает часть проблем XML.

### 2. Hilt (Dependency Injection)
*   Hilt — это стандартная библиотека для внедрения зависимостей в Android. Она минимизирует количество ручного кода для создания объектов (Factory, Containers), управляет их жизненным циклом и гарантирует, что компоненты системы (репозитории, UseCase) будут легко заменяемы и тестируемы.

### 3. Room Persistence Library
*   Room является стандартной библиотекой для работы с SQLite. Я не уверен, есть ли у нее аналоги. Это надежный способ хранения данных заметок локально.

### 4. Coil
*   Coil — это библиотека для загрузки изображений. Она легко интегрируется с Jetpack Compose, эффективно управляет памятью и кэшированием, что критически важно при работе с фотографиями в заметках.

### 5. Navigation Compose
*   Обеспечивает навигацию между экранами внутри единой Activity. Это официальное и удобное решение от Google для Compose-приложений, которое позволяет передавать аргументы между экранами безопасным способом.

### 6. Kotlinx Serialization
*   Используется для преобразования сложных объектов в формат JSON для хранения в базе данных(в моем случае для списка блоков с контентом).
